# AI Engineer workshops

Code for the AI Engineer workshops. One folder per workshop. Start with the README in the workshop's folder.

| Workshop | What you build |
|---|---|
| [business-automations](business-automations/) | Build Professional AI Automations: short Python automations on Google Cloud Run, started by hand, on a schedule or by a webhook. Job leads, speed to lead, receipts, and a video-to-content agent |

## Adding a workshop

1. Make a folder named after the workshop, in kebab-case.
2. Add a `README.md` that says what members build and how to set it up and run it.
3. Keep the code runnable on its own: its own `pyproject.toml`, `.env.example` and tests.
4. Add a row to the table above.
